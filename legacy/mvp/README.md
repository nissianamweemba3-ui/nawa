# DPA Zambia — Compliance MVP

This is a browser-based proof of concept for a Zambia-focused data protection compliance product.

## Run
Open `index.html` in a modern browser. No server is required for this prototype.

## What works
- Organisation profile
- 15-question compliance assessment
- Weighted compliance score
- High/medium priority gap list
- Local browser persistence
- Starter document generator
- Legal source register

## Important
This is not production-ready and does not submit applications to the Data Protection Commission.
Before commercial deployment, add authentication, a real database, tenant isolation, encryption, audit logging, secure document storage, current-source legal versioning, proper AI retrieval, payment, and legal review.

## Legal baseline used for the prototype
The MVP is structured around official Zambia DPC materials including the Data Protection Act No. 3 of 2021, the 2021 Registration and Licensing Regulations, the DPC's registration portal, and official guidance on registration, breaches and Records of Processing Activities.
